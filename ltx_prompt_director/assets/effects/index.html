Import & use

Keep the extracted folders together. The catalog and helper work offline.

For an agent

Give the agent agent.md, then load effects.json or effects.jsonl. Use effect IDs as stable keys and preserve the relative image, clip and audio paths. Load sources/audio.json for sound sample metadata. AGENTS.md points agents to the same instructions.

For a shot

  1. Select one mechanic and, if needed, one animal preset.
  2. Set the subject side, body region and visible ending stage.
  3. Attach the original shot plus the selected actual clip through your model's supported media inputs.
  4. Preview a matched WAV if sound is needed. Explicitly attach it only when the selected host supports an audio input; preserve existing dialogue and timing.
  5. Insert only the chosen segment into the existing shot description. Retain current subject IDs and scene constraints.

A path or URL in prompt text does not upload footage. Gemini video analysis is distinct from edited-video output; choose an interface/model that supports your desired operation.
