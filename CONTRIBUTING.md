# Contributing

1. Create a feature branch from `main`.
2. Use Python 3.10 or newer and install `requirements.txt` in a virtual environment.
3. Keep media processing local and never log or export API keys.
4. Run `python -m compileall -q ltx_prompt_director` before opening a pull request.
5. Describe user-visible changes and test image, WebM, project, and LTX JSON workflows when relevant.
