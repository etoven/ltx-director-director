# Welcome to Aurora.

## A workspace built around the creative sequence

Aurora brings the visual timeline, your intent and the production prompt into one native desktop workspace. Open the app, return to a project and keep shaping the motion from the same place.

![The current Aurora welcome screen and startup status](images/aurora-startup.png)

The startup screen shows progress while Director prepares the panels, text tools and project previews. The interface uses local assets and native desktop controls. Once open, you can arrange the project library, Properties, Preview and Project Files around the way you work.

## Keep the important things in view

Your timeline shows the sequence. The shared editor shows the selected LTX prompt or the full MiniMax brief. Director’s Intent expands when you need to establish the creative throughline and collapses when you want more room to write.

![The Aurora workspace with visual beats and shared segment and unified prompt editing](images/ltx-director-director-overview.png)

Use the toolbar text-scale control to make the interface comfortable on your screen. Your panel arrangement, timeline view and intent-panel state are retained across sessions.

## Write the revision where it belongs

Inline notes make instructions visible inside the draft. Type `/` and press Tab to insert Refinement, Global refinement, Keep, Avoid or Focus. Their outlined presentation keeps the edit request easy to find beside the words it should influence.

![Outlined refinement notes inside the prompt editor](images/inline-refinement-notes.png)

Read the [refinement and audio guide](refinement-and-audio.md) for each note’s purpose, or use the [complete feature guide](../usage.md) to explore the workspace.

LTX Video and MiniMax identify supported video-prompt workflows. Gemini and OpenAI identify supported prompt-generation providers. Third-party marks belong to their owners and do not imply endorsement. Director’s scenic welcome artwork and embedded branding are included with the app.
