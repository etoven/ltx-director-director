# Aurora a113: shared prompt surface and project browser

The panel overhaul follows the six supplied private references. One visible Unified Prompt surface switches between Segment, Global and Unified across LTX and MiniMax timeline workspaces. Each original editor/document and its authoring signals remain intact. Segment targets one beat, Global directs the complete sequence, and Unified edits the independent production text. LTX Unified uses the existing exported global production prompt; its generation/refinement preserves the timeline. Standalone refinement exposes only Unified. Completed-shot sequencing retains its specialized editor.

Compact Quick Fix, Generate, Refine and scope controls live inside the right edge of the editor. Text cannot run underneath the controls. Copy, synchronization arrows, character counts, streaming/progress, inline review, retry/recovery, timing, audio/quality controls, references and local generation remain available. Timeline clicks select Segment scope; combined and segment workers reveal the document that owns their stream. Switching views does not generate or rewrite user content. The timing overview is explicitly retained, including workflow labels, thumbnails, start/end times, its resize handle and hide/reopen gesture. Existing saved panel extents remain authoritative; new installs use the compact timeline default.

Project Library adds collection breadcrumbs and Back/Forward/Home navigation, compact New/Rename/Delete/Catalog/overflow actions, grid/list views, independent card colors and multi-select status filtering. Cards fill available columns and retain thumbnail-size presets. They show a cover, colored top strip/border, title/description and separate status pill. New status defaults include Draft, In progress, Ready, Needs review, Completed and Failed. The old factory set is expanded once, with existing status names preserved; custom definitions remain authoritative. Legacy statuses, no status, extra tags and archive filtering remain in More filters. Sorting, custom drag ordering, duplicate, Properties, collections, notes, archive and confirmed deletion remain available. Saved dock arrangements are retained; fresh layouts tab Project Library beside Effects Library.

The supplied transparent logo is packaged unchanged and used in the top bar and application window. Linux desktop installation now refreshes an existing icon when the packaged artwork changes, even when the launcher text is unchanged. New panel glyphs are repository-native SVGs. All file pickers continue to use the shared KDE-capable route. No model, credential or original media changes are part of this release.

Validation covers scope/document preservation, action routing, LTX production-text generation without timeline mutation, timing-overview retention, standalone/shot-mode behavior, project search/filter/navigation and view state, independent card color, compact/narrow/scaled layout and existing desktop-icon upgrades. Native captures document the real widgets with authored Aurora demo data. The private style guide records the references, palette, dimensions, scope semantics and preservation requirements and remains excluded from Git and wheels. Local verification passed all 97 isolated native editor groups, the six focused panel regressions, and the 240-test release core suite (plus 12 subtests). A clean venv wheel installation verified visible scope switching, independent drafts, scope restoration, copy, timing retention, two-column cards/list view, the icon and bundled manual. ZIP integrity and every packaged source/asset byte match the checkout; private files and bytecode caches are absent. Additional shared-editor/reference/project compatibility checks update obsolete dual-panel assertions; the original historical skill-fixture test explicitly skips when its old Git commit is unavailable. No GPU sampling was performed for this UI release. Publication CI repeats the native/editor checks on the final commit.
