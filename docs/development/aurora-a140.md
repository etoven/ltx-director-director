# Aurora 1.13.0a140 reference reassessment

Reference Media has a dedicated Reassess references action. It reconciles reference use across existing Unified fields, including prose that still cites a deleted audio source. It does not regenerate the document or timeline. The writing model returns exact, minimal text patches in a separate response schema. Invalid targets, missing/ambiguous snippets and overlapping edits are rejected before application. Unchanged passages remain byte-for-byte intact.

The structured editor records compact reference changes, including previous labels and source identity, across deletion, replacement, renumbering and save/load. The reassessment receives current definitions and explicit notes as text context; it does not re-upload or analyze media. Its instructions preserve dialogue and independently requested sound when a reference file is removed. Application checks the original document, references, timeline, workspace and render group before applying patches. A backup of changed fields is retained in project state.

Focused verification covers exact patches, untouched text, empty results and rejection of wrong targets, missing snippets and overlapping edits. The native reference workflow additionally deletes an audio source, clicks the dedicated button, updates summary/shot/sound citations while preserving dialogue and timeline data, saves/reopens, and rejects a result arriving after a user edit. Provider responses are fixtures; no paid requests or model sampling are part of validation. The clean-installed wheel repeats these checks.
