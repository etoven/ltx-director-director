# Aurora a116: native H3 conditioning and live preview

Native video jobs now snapshot the ordered timeline alongside Reference media. Image checkpoints retain their Start/End times; video guides retain their timeline positions and source trims. Archived originals are materialized off the UI thread. Ref2VA guide rows use the target temporal grid while ordinary Reference-panel rows keep their original positions. FL2VA reports unsupported intermediate guides instead of silently using them as opening keyframes. Missing files, invalid short clips and guides beyond the configured duration produce actionable errors. The verbose log lists the conditioning inventory and target frame positions.

The live preview previously projected the high-sigma sampling state, which can remain noise-heavy almost to the end with the shifted H3 schedule. It now projects the existing flow prediction's clean-latent estimate on each step, in float32, without another model pass or VAE decode. All temporal samples are retained and interpolated on H3's 1/4/4/4/4 frame grid. Optional full-VAE previews retain their configured cadence (five steps by default). Settings and the illustrated offline guide describe the distinction.

Reference-video encoding uses 128-pixel spatial tiles after a bounded GPU probe exposed a 7.17 GiB convolution allocation with the larger tiles. The memory allowance now counts reference-video temporal rows. Timeline clips accept the native 17n+5 grid including a five-frame minimum; untimed video references retain the two-second requirement. Packaged VAE converters also accept the lazy disk mapping used when disk offload is disabled.

Validation: the release core suite passed 240 tests and 12 subtests. Seven local-generation UI checks passed in isolated native processes. The private ML runtime passed nine CPU tests covering actual native packed coordinates, untouched ordinary references and target rows, lazy VAE mappings, high-sigma noise cancellation, full-frame preview movies and periodic VAE cadence. The non-ML generation/LoRA/conditioning suite passed 22 tests (11 optional ML tests skipped). An additional CPU-only check encoded a real image with the installed H3 VAE encoder and verified high-sigma clean-latent recovery and RGB projection; the preview remains a coarse color approximation.

The clean-installed a116 wheel passed the native app smoke check and 23 focused generation/UI tests (11 optional ML tests skipped in that Qt-only environment). All 449 packaged source/asset members matched the checkout, with no private files or bytecode caches.

GPU validation remains partial: the revised conditioning passed video/image VAE encoding and prompt/vision encoding, then reached sampling network layer 14 of 50 in the first of 20 steps before the eight-minute cap expired. No sampler step completed and no new GPU preview or finished render was verified. The worker was stopped and the GPU released.
