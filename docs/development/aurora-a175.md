# Aurora a175: durable render queues and queue controls

Queue tile clicks open the associated saved project while retaining other workspace edits. Batch headers retain collapse/expand behavior. Export buttons use the same reserved filenames, configured project/global Downloads directory, background save queue, failure handling and Recent exports tray as other exports; no separate save-location dialog bypasses that workflow. Shift+S invokes Save and Shift+A invokes Save All.

Queue drag feedback paints a visible insertion line, including rejection coloring for invalid dependency/group moves. The cue and drop share one target-position calculation and the queue's existing ordering validation. Native drag feedback is disabled to avoid conflicting indicators.

A versioned, atomic render-queue snapshot preserves order, IDs, dependencies, grouping, history, output paths, mode, progress, authoring inputs and queue-view state. Writes are debounced and coalesced on the existing serialized disk worker. Shutdown captures the queue before cancellation so queued work remains resumable. Reopening restores interrupted renders as pending from the beginning, with the queue paused. Video and image input recipes reconstruct operations rather than serializing Python callables. Credentials are excluded; remote destinations and image provider credentials are resolved from current discovery/settings on resume. Incoming host-only requests without a local project/input recipe are retained as interrupted history requiring resubmission by their client. Unreadable/future-version snapshots are retained instead of being overwritten.

Completed dependency outputs remain available after sweeping history when pending jobs still need them. Restored live preview initializes its playback state, and completed results retain their project/group targeting. Saved empty projects can reopen without the previous main-track-content rejection.

Focused native verification covers project clicks, actual insertion-line pixels, configured-directory video/image exports, both keyboard shortcuts, secret exclusion, queue save/reopen, interrupted and completed states, dependency IDs, resumed video preview and Flux rendering. Existing drop/dependency ordering and the save/naming/shutdown scenario were also checked. Clean-installed wheel verification reuses the same focused workflow; broader CI runs separately.
