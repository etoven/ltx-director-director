# Aurora a102: native model repair

The a101 package-presence check accepted an incomplete inference environment even though PyTorch could not import. Preparation now installs dependencies and its download cache inside Director's managed engine venv, checks dependency consistency, imports the actual pipeline classes and executes a CUDA tensor operation before reporting success. The wheel includes this preparation code; ML packages are downloaded into the private venv rather than installed globally.

The native H3 adapter accepts the existing NVFP4/AWQ Qwen3-VL encoder without replacing its weights. Packed matrices stream from disk and use per-layer BF16 computation, including AWQ input scaling and the scaled INT8 embedding. The packaged video VAE's extra statistics and the audio VAE's already-normalized convolution weights are adapted to the native implementation. Single-frame VAE convolutions and Qwen's patch-sized projection use equivalent 2D/matrix operations to avoid the observed slow 3D-convolution paths. CUDA 13 installations on compatible drivers use native comfy-kitchen kernels. CUDA 12 INT8 layers use the library's PyTorch/cuBLAS backend rather than a lengthy Triton autotuning sweep; NVFP4 dequantization retains its own backend selection.

Generate locally uses the current unified production output and a snapshot of the existing Reference panel directly. Canvas, duration, sampler, steps and random/static seeds live in Local models settings; the redundant generation dialog is removed. Paired reference-video audio is kept with its video, and audio references use the bundled PyAV decoder instead of requiring an additional system-linked decoder. The resolved seed is reported in output. Generation panels and effect-thumbnail creation show bounded, copyable verbose output. Both worker streams and tracebacks are delivered live with credentials redacted; raw requests and logs are not retained on disk. A terminal result releases its private process promptly instead of waiting for large-model Python teardown.

The scanner excludes speech-model folders from automatic writer selection. On this workstation, the existing Qwen2.5 3B instruction weights were paired with their official configuration/tokenizer, and the saved writing choice was corrected from the speech-emotion checkpoint. Original model weights and catalog artwork are unchanged.

The supplied Comfy workflow was read as configuration data. Its active group overrides resolve to 16:9, 0.5 × 1024² pixels rounded to multiples of 32 (960 × 544), 15 seconds aligned to 362 frames at 24 fps, 20 steps, RES multistep/simple, guidance 1 and fixed seed 931351171509952. The selected files are the pruned INT8 Ref2VA DiT, NVFP4/AWQ Qwen3-VL encoder, FP16 video VAE and FP32 audio VAE. Lightning and the optional motion LoRA are disabled. Its authored prompt and media are not included in the package. Native defaults now match that canvas, duration, steps and sampler; seed controls accept unsigned 64-bit values. The erroneous aligned-duration ceiling is removed. The RES integrator carries audio on the video schedule with the corresponding audio normalization, without importing ComfyUI.

Reference preprocessing is capped to the output canvas rather than the upstream default 2048-pixel shortest edge. INT8 projections process bounded row batches, and the entire gated feed-forward pair streams in row batches to bound intermediate memory. Activation budgeting accounts for both the VAE's 16× downsampling and the DiT's 2×2 latent patch packing. The full-video inverse normalization consumes its private decoder buffer in temporal chunks, avoiding additional whole-clip allocations. Free and total GPU memory and the weight cache threshold are included in verbose output. Worker imports expose only backend source and resolve all ML dependencies from the selected private interpreter, without borrowing GUI site-packages.

## Validation

Hardware: RTX 3060 12 GB, 16 GB system RAM. The final managed runtime uses PyTorch 2.9.1+cu130, pinned DiffSynth revision 681c456a3e8cf9e17cf2cb9a35297718ed4270ca, Diffusers 0.41.0, Transformers 5.20.2 and comfy-kitchen 0.2.39. The installer selects CUDA 13 for R580+ drivers with compute capability 7.5+, with a CUDA 12 fallback. Dependencies, build temporaries and caches stay inside the private venv. ComfyUI and original checkpoint files were left alone.

- Actual H3 conditioning completed all 27 vision blocks and 50 language blocks using the 14 GB NVFP4/AWQ encoder. The pruned joint video/audio model completed the first whole sampling step at 960×544, 362 frames, the configured 20-step RES schedule and workflow seed, on both CUDA 12 and CUDA 13. The user explicitly chose one completed sampler step as the validation boundary; a full 20-step quality render was not performed.
- CUDA 13 saved the first-step 17-frame video preview. A subsequent full decode exposed an allocation spike during whole-video pixel normalization; chunked conversion now matches the original transform exactly on CPU. After that fix, the actual video and audio VAEs decoded synthetic full-duration latents to 362 frames at 960×544 and stereo audio, with finite output. The resulting H.264/AAC file passed independent PyAV readback (362 frames, 24 fps, 15.083 seconds, stereo 32 kHz). The synthetic decoder diagnostic is a component check, not a finished generation.
- Actual CUDA Flux 4B renders completed: CUDA 12 two-step 256×256 text-only, 256×256 image reference, and 1024×1024 text-only; CUDA 13 one-step 256×256. Each decoded a draft preview and saved a final PNG. These are pipeline checks, not quality benchmarks.
- Actual Qwen2.5 3B instruction-model inference returned valid prompt JSON under both CUDA runtimes using the existing complete checkpoint.
- A real pruned DiT INT8 QKV matrix completed native CUDA 13 inference with finite output and relative error 0.00995 against dequantized BF16 inference. Independent RES joint video/audio numerical comparison passed within 1e-7.
- Both packaged VAEs' converted keys and shapes matched the native architectures exactly. CPU numerical comparisons passed for patch projection and single-frame convolution replacement, including spatial and temporal padding cases. Real audio-reference encoding and full audio decoding passed.
- Private engine dependency/import/CUDA probes passed. Core transport, cancellation, redaction, scanner, frame-alignment and 64-bit seed regressions passed (16 passed, 5 optional-ML skips in the final core run). Five native UI groups passed separately with isolated XDG directories, including direct unified-output/Reference-panel wiring and settings persistence. Reference, media preservation, export and verbose-pane regressions passed.
- Installed-wheel verification and publication results are recorded with the release commit and CI run.

`scripts/check_local_models.py` runs actual inference through the same worker transport as the UI. It supports encoder overrides, reference files, canvas, duration, steps and seed without modifying saved settings. Low default step counts exercise the pipeline rather than final quality. `--prompt-file` accepts exported unified output verbatim; `--stop-after-step 1` exercises the configured schedule through its first complete step and explicitly labels the output unfinished.
