# ComfyUI export artwork

The ComfyUI export action uses the official Comfy logo from [Comfy-Org/ComfyUI_frontend](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/public/assets/images/comfy-logo-single.svg), used to identify the export destination. Source repository [license](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/LICENSE). The mark identifies ComfyUI; this application is Prompt Director.

The packaged graph is adapted from the user-supplied MiniMax workflow. Its source media names, editor previews and scene prompt are removed; export fills them from the current project.
